## ModelAnnotation

Level 1 of the AILM hierarchy: a directly-observed Markov chain over the 30
symbols of the AILM alphabet (a-z, space, period, apostrophe, hyphen).

- Hidden factor: the current letter, 30 states.
- Observation modality: the current letter, 30 observations.
- A is the identity. The letter is observed directly, so the recognition matrix
  carries no learned content at this level.
- B is the Brown-corpus letter bigram transition, B[next, current].
- D is uniform: before the first letter the model knows nothing.
- C is flat. This level expresses no preferences and selects no actions; at
  generation time the preference vector is supplied by the level above.

Where the learned statistics live. The bigram counts parameterize the
TRANSITION, not the emission. This is the load-bearing modeling decision in
AILM and the one its worst shipped bug got backwards. Putting the bigram table
in A with an identity B is anti-informative rather than loudly broken: observing
letter c yields a posterior over the letter that PRECEDED c, and an identity B
carries that backward-looking belief forward as the prediction for the next
letter. Measured, that wiring scores claim:stage1_anti_informative_perplexity
against claim:stage1_letter_perplexity for the wiring specified here. pymdp
cannot catch it — a bigram matrix is column-stochastic and passes validation in
either slot, and both wirings produce identical matrix shapes. The
ActInfOntologyAnnotation and InitialParameterization blocks below are what pin
the orientation by name.

Gate. Stage 1 is gated on beating the CONTEXT-FREE unigram baseline
(claim:stage1_unigram_baseline), not on beating uniform
(claim:stage1_uniform_baseline). Uniform is a crippled comparator: a model can
clear it while using no context at all. The agent reaches
claim:stage1_letter_perplexity. The original target of
claim:stage1_declared_gate_nats nats below uniform was
information-theoretically unreachable at bigram order and was withdrawn.

Learned entries are a derived artifact, not part of this specification. The
bigram table is reproduced byte-identically from the vendored counts by its
generator; InitialParameterization names the generator and the artifact rather
than inlining the matrix, so there is exactly one source of truth for the
numbers.

## InitialParameterization

# A is the identity: the observed letter IS the hidden letter. This is a
# structural claim about the model, not a learned quantity.

A=Identity(30)

# B holds the learned Brown letter-bigram statistics. The entries are a derived
# artifact regenerated byte-identically by the generator named here; they are
# deliberately NOT inlined, so the vendored counts stay the single source of
# truth for the numbers.

B=Learned(generator=scripts/generate_counts.py, artifact=vendor/brown_counts.json, estimator=add-1-Laplace, normalization=column-stochastic-over-next-letter)

# C is flat — no preference over observations at this level.

C=Zeros(30)

# D is uniform — no information about the first letter.

D=Uniform(30)

## Equations

# Predictive belief over the current letter, the posterior pushed through B

pred_t = B * q_{t-1}

# Predictive likelihood of the letter actually observed

P(o_t) = sum_j A[o_t, j] * pred_t[j]

# Posterior over the current letter after observing it

q_t = normalize(A[o_t, ] * pred_t)

# Per-letter perplexity over T scored positions

PP = exp(-(1/T) * sum_t ln P(o_t))

# the phoneme level performs at every word boundary has no analogue here.
